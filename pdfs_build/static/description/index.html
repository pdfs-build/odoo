Your design replaces Odoo's own Invoice PDF: the Print button, Send by email, the customer portal and the PDF stored on the invoice all use it. Odoo's e-invoice XML (Factur-X, UBL) is still embedded.

Ready-made designs, one click, no mapping

Designs for Odoo lists invoice, quotation, purchase order and delivery slip designs with previews. Click one: it is copied into your pdfs.build organization and its report is created, already reading the right Odoo fields. It takes your company logo and document-layout colors from Odoo's settings.

Two designs for each document type, from bold to conservative, and more on pdfs.build/templates. Want something else? Describe the document to the pdfs.build AI designer, or edit any design visually with live preview, then print it from Odoo.

Up and running in three steps

1. Connect

Start the free trial, create an API key, and paste it with your organization ID in pdfs.build > Settings.

2. Pick a design

Add one from Designs for Odoo, or sync your own templates. Preview the PDF on a real record before going live.

3. Print

Use it for Odoo's Invoices or Quotation / Order report, or add it as a new entry in the Print menu.

Preview in Odoo, take over Odoo's own reports

Preview PDF renders the record you pick and shows it in Odoo's PDF viewer.

Use for Existing Report hands Invoices, Quotation / Order or any other Odoo PDF report to a design. Clear it to go back.

Your own templates, mapped in the form

For a template of your own, the report's data is written for you from the template's fields: everything that matches an Odoo field, lines and nested records included, is filled in. The rest is a short Python expression, with both sides listed next to it.

Features

For your business

  • Invoices, quotations, purchase orders, delivery slips, or any other Odoo document
  • Each document in its customer's language: translated fields, dates and amounts
  • Email attachments, portal downloads and stored invoice PDFs use your design
  • Odoo's e-invoice XML embedding (Factur-X, UBL) still applies
  • Keeps invoices going out: a replaced Odoo report falls back to Odoo's layout if pdfs.build cannot render
  • Print many records at once: rendered in parallel and merged into one PDF

For administrators

  • Preview the data and the PDF on any record before going live
  • The data mapping is written for you from the template's fields; helpers for images, dates, amounts and taxes
  • Errors from pdfs.build shown with the field or line concerned
  • Pin a template version per report, so design changes never break printing
  • Save as attachment and reload from attachment, like any Odoo report
  • Odoo 17, Community and Enterprise; free and open source (LGPL-3)

What you need

This module uses the external service pdfs.build. You need a pdfs.build account with API access and at least one published template, or a design added from Designs for Odoo. New accounts start with a 7-day free trial that includes the API; plans start at $19 a month after it.

Every print sends the data produced by the report, together with your API key, to api.pdfs.build. Nothing else leaves your Odoo. Render logs on pdfs.build keep the data payload for your audit trail.
